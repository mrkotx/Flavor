# Flavor

Приложение для рецептов, где можно делиться своими блюдами и сохранять чужие.

## Что умеет

- **Смотреть ленту** — все рецепты, которые пользователи выложили, с фильтром по категориям (завтрак, обед, ужин, перекус или всё сразу)
- **Добавлять свои** — если зарегистрироваться, можно выложить рецепт с названием, описанием, списком ингредиентов и инструкцией
- **Сохранять чужие** — нажал на сердечко, рецепт упал в избранное
- **Личный кабинет** — возможность выкладывать свои рецепты и получать лайки
- **Редактировать** — свои рецепты можно менять или удалять
- **Поиск рецептов** — окно с поиском по названию
- **Тёмная тема** — если на телефоне включена тёмная тема, приложение тоже станет тёмным

## Зависимости

- Firebase (Auth, Realtime DB, Storage)
- Material Components (кнопки, карточки)
